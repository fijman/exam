# Система экзаменов с SQLite базой данных

Этот проект представляет собой систему экзаменов, которая была мигрирована с JSON файлов на SQLite базу данных для улучшения производительности и масштабируемости.

## Структура базы данных

### Таблицы:
1. **users** - пользователи системы
   - `id` - уникальный идентификатор
   - `username` - имя пользователя (имя и фамилия)
   - `password` - хешированный пароль
   - `access_level` - уровень доступа (user, admin)

2. **access_codes** - коды доступа к системе (для совместимости)
   - `id` - уникальный идентификатор
   - `code` - код доступа
   - `valid` - действительность кода (1/0)
   - `comment` - комментарий к коду

3. **code_access_types** - типы доступа для каждого кода
   - `id` - уникальный идентификатор
   - `code_id` - ссылка на код доступа
   - `access_type` - тип доступа (advocate, senior_advocate, zpka)

4. **questions** - вопросы для экзаменов
   - `id` - уникальный идентификатор
   - `text` - текст вопроса
   - `points` - количество баллов за вопрос
   - `explanation` - объяснение ответа
   - `test_type` - тип экзамена

## Установка и запуск

### 1. Установка зависимостей
```bash
npm install
```

### 2. Инициализация базы данных
```bash
npm run init-db
```
Этот скрипт создаст базу данных `exam_database.db` и заполнит её данными из JSON файлов.

### 3. Запуск сервера
```bash
npm start
```
или для разработки:
```bash
npm run dev
```

Сервер будет доступен по адресу: http://localhost:3000

## Система авторизации

### Требования к учетным данным:
- **Имя пользователя**: должно состоять из двух слов (имя и фамилия)
- **Пароль**: минимум 8 символов, одна заглавная буква и цифра

### Учетные данные администратора:
- **Логин**: `Admin_Admin`
- **Пароль**: `Tdf12588`

## API Endpoints

### Авторизация пользователя
```
POST /api/login
Content-Type: application/json

{
  "username": "Имя Фамилия",
  "password": "Пароль123"
}
```

### Регистрация пользователя
```
POST /api/register
Content-Type: application/json

{
  "username": "Имя Фамилия",
  "password": "Пароль123"
}
```

### Проверка кода доступа (для совместимости)
```
GET /api/check-code/:code
```
Возвращает информацию о коде доступа и разрешенных типах экзаменов.

### Получение вопросов
```
GET /api/questions/:examType
```
Возвращает все вопросы для указанного типа экзамена в случайном порядке.

### Получение отфильтрованных вопросов
```
GET /api/questions/:examType/filtered?count=10
```
Возвращает отфильтрованные вопросы с учетом распределения по баллам.

## Миграция с JSON

Проект был успешно мигрирован с JSON файлов на SQLite базу данных:

- `code.json` → таблицы `access_codes` и `code_access_types`
- `advocate.json` → таблица `questions` с `test_type = 'advocate'`
- `senior_advocate.json` → таблица `questions` с `test_type = 'senior_advocate'`
- `zpka.json` → таблица `questions` с `test_type = 'zpka'`

## Преимущества SQLite

1. **Производительность** - быстрые запросы к базе данных
2. **Масштабируемость** - легко добавлять новые вопросы и коды
3. **Целостность данных** - использование внешних ключей и ограничений
4. **Безопасность** - защита от SQL-инъекций через параметризованные запросы
5. **Удобство управления** - возможность легко редактировать данные через SQL
